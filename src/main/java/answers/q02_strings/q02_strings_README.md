# Exercise q02_strings — Strings, .equals vs ==

Implement `sameContent` (content equality), `sameObject` (reference equality) and `shout` (upper-case + `!`). The test builds strings with `new String(...)` so content-equal strings are NOT the same object — exactly the `.equals` vs `==` lesson.

Run the test:

```bash
make test-one TEST=Q02StringsTest
```
